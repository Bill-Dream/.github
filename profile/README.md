## ✨ 빌드림이 제공하는 솔루션

### 📝 **다양한 문서 템플릿**

- 청구서, 견적서, 계약서, 세금계산서 4가지 문서 유형 지원
- 문서 유형별 맞춤 입력 필드 제공
- 전문적인 디자인의 PDF 자동 생성

### ⚡ **자동 계산 기능**

- 수량과 단가 입력 시 공급가액, 부가세, 합계 자동 계산
- 실시간 미리보기로 즉시 확인

### ✍️ **전자 서명**

- 계약서에 공급자/수급자 전자 서명 기능
- 캔버스 기반 자필 서명 지원

### 📱 **반응형 디자인**

- 데스크톱, 태블릿, 모바일 완벽 지원
- PWA 지원으로 앱처럼 설치 가능

## 🚀 주요 기능

### 📝 **문서 관리**

| 문서 유형   | 특화 기능                              |
| ----------- | -------------------------------------- |
| 청구서      | 은행 계좌 정보, 입금 안내              |
| 견적서      | 유효기간 설정, 빠른 날짜 선택          |
| 계약서      | 계약 조건, 공급자/수급자 전자 서명     |
| 세금계산서  | 공급자 정보 (사업자등록번호, 업태 등)  |

### 👥 **거래처 관리**

- 거래처별 연락처, 사업자정보 통합 관리
- 거래처별 문서 히스토리 추적
- 문서 작성 시 거래처 정보 자동 불러오기

### 📊 **프로젝트 관리**

- 프로젝트 단위로 문서 그룹화
- 프로젝트별 매출/수익 현황 파악
- 진행 상태 관리 (진행중/완료/보류)

### 📈 **대시보드**

- 이번 달 매출 현황
- 최근 발행 문서
- 미결제 건 알림
- 거래처/프로젝트별 통계

<br />

## 🎯 서비스 대상

### 🎨 **크리에이티브 프리랜서**

- 웹/앱 개발자, 디자이너, 컨설턴트
- 복잡한 회계 프로그램 없이 간단한 정산 관리가 필요한 분들

### 🏪 **소상공인**

- 온라인 쇼핑몰, 카페, 작은 서비스업
- 고객별 맞춤 견적과 정산이 필요한 사업자

### 👨‍💼 **1인 기업/스타트업**

- 초기 단계에서 비용 효율적인 업무 관리 툴이 필요한 팀
- 성장에 따라 확장 가능한 솔루션을 원하는 기업

## 🏃‍♂️ 로컬 개발 환경 설정

```bash
# 저장소 클론
git clone https://github.com/Bill-Dream/billdream.git
cd billdream

# 의존성 설치
npm install

# 환경 변수 설정
cp .env.example .env.local
# .env.local 파일에 필요한 환경 변수 입력

# Prisma 클라이언트 생성
npx prisma generate

# 개발 서버 실행
npm run dev
```
